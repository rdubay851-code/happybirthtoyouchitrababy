# CHITRA — A Sky Written For You

## GitHub Pages
Extract this ZIP and upload these files directly to the repository root:
- index.html
- styles.css
- app.js
- README.md

GitHub Pages → Settings → Pages → Deploy from branch → main → /(root).

## Creator preview
Before July 3, 2027, click CREATOR PREVIEW on the home page and enter:
`chitra-creator-2027`

Or open:
`?creator=1`

Creator preview is browser/session-only.

## Birthday unlock
The target is July 3, 2027 at 00:00 India Standard Time.
On/after that moment:
- the normal visitor sees every room open
- creator preview is no longer shown
- the final birthday room opens
- navigation remains available
